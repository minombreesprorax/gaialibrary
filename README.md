# Gaia Library

La biblioteca de Gaia para Kamen Rider — un sitio de referencia estático hecho por fans.

El sitio es la entrada a la colección de **Heisei Fase II** (2009–2019).
La estructura, la navegación, el estante de series y las secciones de estado ya están
listos; las fichas detalladas se irán añadiendo a medida que se escriban.

El sitio está en español por ahora. La traducción al inglés está prevista para más
adelante.

## Estructura

- `index.html` — inicio: presentación de la era y muestra del estante
- `la-era.html` — las tres eras y la línea de tiempo de las diez series
- `coleccion.html` — el estante completo, con enlaces a la línea de tiempo
- `acerca.html` — propósito del proyecto, estado y organización
- `styles.css` — todos los estilos (sin JavaScript)
- `FONT/` — fuentes locales de títulos y texto japonés
- `favicon.svg` — icono del sitio

## Ejecutar en local

Abre `index.html` directamente o sirve la carpeta con cualquier servidor de archivos
estáticos. El sitio está listo para publicarse en GitHub Pages desde la rama `main`.
