図書館 · La biblioteca

Sobre este proyecto

Qué es Gaia Library, en qué estado está la colección de Heisei Fase II y cómo se organizará cuando las fichas empiecen a escribirse.

Gaia Library es una referencia estática hecha por fans para Kamen Rider. Esta página es la entrada a la colección de Heisei Fase II; el resto del estante se abrirá a medida que se escriba.

La estructura está lista antes que el contenido. Las fichas de series, los registros de riders y las notas de episodios están planificados para que las entradas puedan añadirse sin reconstruir la página.
